## Current repository alignment and affected modules

Present: native password/session authority, direct Google subject linking, governed eligibility, global idempotency, audit/outbox/inbox, balanced journal, shared collateral reservations, synthetic partner/chain funding workflows, market governance and OpenAPI/types. Missing: production contact delivery validation, privileged MFA, durable global abuse controls, independently observed USDT deposits, independent partner reconciliation and production chain adapters. Synthetic `DEMO` is neither NGN nor USD and must not be relabelled as either.

Provider ports belong in identity/contact, identity/verification, notifications and funding/fiat modules. Provider adapters must map documented external responses into normalized Afridict states and retain opaque provider references. Webhook authenticity, durable event identity, replay/reorder policy and independent reconciliation precede financial posting. Domain code must not import provider SDK types. No provider credential appears in frontend contracts, logs, examples or events.

The registration contact state is REGISTERED -> EMAIL_VERIFIED -> PHONE_VERIFIED -> ENTERED, with a separate identity path NOT_STARTED -> PENDING/IN_REVIEW -> VERIFIED/FAILED/REQUIRES_RETRY. NGN deposit is REQUESTED -> INSTRUCTIONS_ISSUED -> PROVIDER_PENDING -> SETTLED/FAILED/EXPIRED/REVERSED, then one balanced ledger effect under approved settlement rules. NGN payout is REQUESTED -> RESERVED -> SUBMISSION_UNKNOWN/SUBMITTED -> RECONCILED_COMPLETED or RECONCILED_FAILED/EXCEPTION; an unknown provider result retains the reservation. These are design states, not claims that SwervPay uses the same vocabulary.

Tests must cover contact resend/attempt/IP/destination limits, timeout and recovery; Persona duplicate/out-of-order events; capability denial; provider deposits under replay/reorder, bank name resolution, payout lost response, ledger conservation, independent reconciliation and controlled compensation. Real activation needs reviewed provider documents and commercial terms, authenticated sending domain and suppression handling, approved identity/NGN policies, safeguarding/accounting, security review, production rate-limit storage and rollout/rollback runbooks.
